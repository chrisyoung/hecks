## What they asked for

Make bugs, tests and sessions first-class runtime citizens instead of markdown:
"Instead of editing FINDINGS.md manually — dispatch commands." Four aggregates
(`Bug`, `QASession`, `TestCase`, `TestCoverage`), a workflow that cannot be
skipped, and queries that answer coverage.

Their explicit success criteria:
- [x] Start a session — `Session.Start`
- [x] Discover a bug — `Bug.Discover`
- [x] Record a fix with a commit — `Bug.Fix commit:`
- [x] Verify it — `Bug.Verify`
- [x] Query status — `Bug.Unfixed`, `.BySeverity`, `.Paused`, `.Blocked`
- [x] Check coverage — `Session.TestCase.ForDomain` / `.InCategory`
- [x] Enforce the workflow — required argument, lifecycle edge, required reference

### Shape
The thing this chapter is about is the **bug**, not the session — so `Session`,
not `QASession`.

- Heads: `Bug` (a Remedy and a Ticket must point at it), `Remedy` (holds a list;
  must be pointed at), `Ticket`, `Session`.
- Entity: `TestCase` — never meaningful without its session, and an entity query
  answers across every parent, which was the only reason they wanted it as a head.
- Dropped: `TestCoverage`. Every field is a count of another aggregate's rows and
  **nothing in the language can maintain it** — an entity command lands on the
  entity, a foreign aggregate's on itself. Same rule removed three requested
  `Session` counters.
- Enforced vs surfaced: `Fix` requires a `CommitRef` (argument, refused at
  coercion); `verified` has one inbound edge; `Ticket.Draft` requires
  `reference_to Remedy`, which is how "fix first, file second" became mechanical.
  Everything cross-aggregate that could not be a reference is a dotted-`where`
  query whose `description` says it is surfaced.

## Found on the way

Four real bugs, none of them mine. All reproduced, none guessed.

| Ref | What | Handed to / fixed |
|---|---|---|
| `BUG#11` | `.strip` in a predicate degrades to a path lookup and breaks **every** dispatch through the value object — 77 of 84 suite failures | fix proven (`pattern:`), handed to the QA engineer |
| `BUG#12` | array `in:` in a `where` is stringified and can never match. Silent | worked around; worth a repo-wide audit |
| `BUG#13` | `ne: ""` becomes `ne: nil` and matches every row. Silent | worked around with a sentinel |
| `BUG#14` | reading `runtime.events` freezes the runtime's **live** log; every later dispatch raises `FrozenError` | fix proven (`.dup.freeze`), handed over |

`BUG#11` and `BUG#14` are both from commits the QA engineer recorded as FIXED in
`qa/FINDINGS.md` this same session, and both are "make it immutable" changes that
broke a **valid** operation. That is the shape their eight adversarial categories
cannot see — every one of them asserts that something invalid is refused, and an
over-strict system passes all eight. Recommended a ninth category.

The branch had never been pushed, so the pre-push hook that runs the full suite
never fired.

## What the language taught me

Everything in `modelling/MODELLING_HAZARDS.md` — written today, from this
engagement. The ones that cost real time:

- **C1** — an unknown method in a predicate is not refused; it is read as a dotted
  attribute path and raises `TypeError` at dispatch. The single most expensive
  hazard in the language.
- **D1/D2** — two silent `where` failures. Assert on contents, never on absence
  of error.
- **C3** — a counter is only honest if its own aggregate's commands move it. This
  killed a requested aggregate and three requested fields, and it will come up
  every engagement.
- **C5** — a required `reference_to` is the strongest enforceable cross-aggregate
  rule available, and only works if the target is a head.
- **E** — the entity-row parent stamp is `:session`, while a head's reference
  attribute is `:session_id`. Two naming paths, both right.
