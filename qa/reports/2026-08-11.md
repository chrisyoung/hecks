## Key Decision: "Fix First, File Second"
Updated SOP to emphasize that QA should **attempt to fix bugs before filing GitHub issues**. Only file issues when:
- Fix is architectural (requires major refactor)
- Fix is too complex for 30-minute window
- Additional investigation is needed

This keeps the issue backlog focused on real blockers, not problems with quick solutions.
