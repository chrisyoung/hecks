# Implemented documentation

This folder holds documentation for features, decisions, and mechanisms that
are fully built and shipped — reference guides for the working DSL, ADRs
whose decisions have landed in code, and resolution-rule specs whose
algorithms are implemented (and, where applicable, mirrored in Rust) today.

`docs/` proper holds everything still in motion: active plans, proposals,
open PRDs, bug audits with unresolved findings, and ADRs not yet built. If a
doc names concrete unbuilt work as still open, it stays there rather than
here.
